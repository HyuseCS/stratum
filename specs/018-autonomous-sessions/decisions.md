# Decisions: #77 autonomous mode in more than one worktree (Define)

- D19 (Q19): One file per session: `<main checkout>/.stratum/autonomous/<session id>`. On makes this session's file, off removes only this session's file; readers check that `<folder>/<this session id>` exists. A session id must match letters, digits and `-` only. Lock 2 still matches `.stratum/autonomous`. An old single-file flag is replaced when a session turns the mode on. Same layout on a saved machine. Rejected: O1, one line per session id in the same file.
- D20 (Q20): No cleanup of other sessions' files. Instead the session turns its own mode off as soon as its task is finished (Build or worker run ends), when the user says "stop autonomous", and also when the user says they will continue some other time (before the handoff). Only a crashed session leaves a file, and that file affects only its own session id. Rejected: O42, remove files older than 24 hours.
- D21 (O54): The user added two fixes to #77: `answer` treats the "Ready to submit your answers?" screen as a question (FR-014), and the orchestrator approves a one-time yes on a cut-off permission dialog when the visible part is safe and the hidden part can only be the worker's own worktree or scratchpad (FR-015). Rejected: separate issues.
