# Decisions: #93 autonomous mode prompts (grill 2026-11-09)

- D2 (Q3): O1. #93 is one Full-lane feature with three user stories, built in the order part 2 (redraw-safe `answer`), part 1 (git-guard asks), part 3 (exact Codex answer). Not built at the same time as #94. Rejected: O2, three separate changes.
- D3 (Q4): O3. `answer` hashes only the dialog block (title line to last option line), not the whole 40-line screen. Callers keep `--screen <hash>`. A changed dialog still gives a new hash and is refused. A dialog cut off at the top still goes to the user; part 1 covers the full command. Rejected: O4, `--expect <text>`.
- D4 (Q5): O7. Part 1: the approve hook stays strict. The git guard denies a `git commit` with a heredoc or `$(` and its reason says to use `git commit -m 'subject' -m 'body'`; the agent retries with plain `-m`, which reaches the orchestrator in full through the approve channel. Not `-F <file>`: the request would hold only the file name. `push` stays with the user. Research: a PreToolUse `ask` still fires PermissionRequest in interactive workers; the dialogs stayed in the pane because `commit_check` (hooks/st-approve.py:193-226) drops heredoc and `$(` commits. Rejected: O5 (brief rule only), O6 (widen the hook to heredoc, `$(` and push).
- D5 (Q6): O8. Part 3: the advisor reads the Codex tab's answer from Codex's session log (`~/.codex/sessions/YYYY/MM/DD/rollout-*.jsonl`, `task_complete.last_agent_message`), found by the run's nonce. No log found: treat it as a failed tab and run the review headless (`codex exec -o`, exact text), with the line `codex: headless (no session log)`. Headless fails too: BLOCKED as today. The screen is never used for the answer. Accepted cost: a rare second Codex run, sharing the same time budget. Rejected: O9 (encoded answer on screen), O10 (BLOCKED at once, no second run).
- D6 (Q7): O11. The git guard denies heredoc and `$(` commits in every session, not only worker or autonomous ones. `agents/st-git.md` also says to commit with `-m 'subject' -m 'body'`. Rejected: O12 (deny only in worker or autonomous sessions, needs a mode check).
- D7 (Q8): O13. `quickstart.md` gets a live check before merge, with a real herdr worker and a real Codex tab: (1) a heredoc commit is denied, retried with `-m` and reaches the orchestrator in full; (2) `answer` works on a worker whose screen keeps changing; (3) a Codex answer with backticks and `"` comes back exact from the log. Rejected: O14 (unit tests only).
- D8 (Q9): O15, with the scope chosen by the user. `st-init` and `st-update` ask once where to turn off Claude Code's built-in git instructions (`includeGitInstructions: false`): project `.claude/settings.json` (recommended, all machines), user `~/.claude/settings.json` (all projects, this machine), local `.claude/settings.local.json` (this repo, this machine), or not at all. The `-m 'subject' -m 'body'` rule goes into the Stratum session text and `agents/st-git.md`. The guard deny (D6) stays as the backstop. Rejected: O16 (guard only).
  - D8a (user, after Q9): the scope question lives in `st-init` for good. In `st-update` it is a one-time step, marked with a `ponytail:` note naming its removal trigger: every Stratum checkout on the PC and the laptop has run the update. Then the step is removed to keep the skill small.
- D9 (Q10): O17. The approve hook stays as it is: a backtick, `$(`, `${`, `<(` or `>(` anywhere in a commit command, also inside quotes, makes it refuse. The git guard denies the same commits, with the same test, and its reason says to use `-m 'subject' -m 'body'` with no backticks or `$(`. Commit messages lose backtick formatting (1 of the last 200 commits used it). Rejected: O18 (teach the hook that single-quoted backticks are harmless; it changes the security parser).
- Note (fact, no question): headless `claude -p` workers never commit (scripts/st-worker.sh:759, `--permission-mode dontAsk`), so the open Claude Code issue on `-p` (PreToolUse `ask` skips PermissionRequest) does not touch #93.
- Note (small decision): D3 covers `st-worker.sh answer` only. `st-advisor.sh answer` also hashes 20 screen lines of the Codex tab, but a waiting Codex prompt has not been seen to redraw, so it stays as is.
