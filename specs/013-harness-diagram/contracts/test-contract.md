# Contract: `tests/test_harness_model.sh`

## Call

```bash
bash tests/test_harness_model.sh [check...]
```

- No argument: run every check, in the order of the table below.
- With arguments: run only the named checks. An unknown name prints `FAIL unknown check <name>`.
- `ST_ROOT=<folder>` makes the test read that folder in place of the repo (as
  `tests/test_local_files.sh` does), for negative controls in a copy.
- The pinned version is one variable, `v=1.60.0`. Every `npx` call is `npx -y "likec4@$v"`.
- The test never writes in the repo. Temp files go in `mktemp -d`, removed by `trap ... EXIT`.
  It needs no `[lock]`.
- Bash, with an inline `python3` parser for the block checks. No other tool.

## Output

One line per result, the same shape as the other tests in `tests/`:

```text
ok   <check>: <what passed>
FAIL <check>: <what failed, with the name or path>
SKIP <check>: <reason>
```

Exit 1 if any line is FAIL, else 0. SKIP does not fail.
