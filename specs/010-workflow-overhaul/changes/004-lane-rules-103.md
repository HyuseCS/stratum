## Files
- scripts/st-shell-writes.sh (new) - `st-shell-writes.sh <transcript.jsonl>...`. Reads each JSONL line of type `assistant`, takes the `command` of every `Bash` tool_use, and prints each command that matches a shell file write: a heredoc (`<<` not part of `<<<`), `tee` after a pipe, `sed -i` (also combined flags such as `-ni`, and `--in-place`), or a `cat`, `echo` or `printf` redirect to a file (`>` or `>>` not followed by `&`, and not to `/dev/null`). Exit 1 on a match, 0 on none, 2 on a missing or unreadable file. Only Bash commands are read, so a Write call or a brief that quotes `<<` does not match.
